## Golden Rules Framework

Score each rule 1-5:

**Clarity** (1-5): Is the response understandable? Does it answer the customer's question directly? Does it avoid jargon?
- 5: Crystal clear, directly addresses the issue, plain language
- 3: Mostly clear but could be more direct or has some ambiguity
- 1: Confusing, doesn't address the question, uses unexplained technical terms

**Empathy** (1-5): Does it acknowledge the customer's situation? Does it show understanding?
- 5: Genuinely acknowledges the impact, shows understanding of frustration
- 3: Polite but generic acknowledgement
- 1: No acknowledgement, dismissive, or uses empty phrases like "sorry for any inconvenience"

**Action** (1-5): Does it state a clear next step? Does the customer know what happens next?
- 5: Clear next action with timeline/expectation ("I'll check X and update you by end of day")
- 3: Vague next step ("We'll look into it")
- 1: No next step mentioned

**Ownership** (1-5): Does it confirm who owns the next action? Is there accountability?
- 5: Clear ownership ("I'm taking this on" or "You'll need to do X, then I'll handle Y")
- 3: Implied ownership but not explicit
- 1: No ownership, passive voice, "the team will"

## Your Task

1. Score each Golden Rule dimension
2. Calculate overall score (average of 4 dimensions, to 1 decimal)
3. List specific strengths (what the agent did well)
4. List specific improvements (what could be better — be constructive, not harsh)
5. Generate nudges if issues are detected:
   - "missing_next_update": No clear next step or timeline
   - "weak_reply": Response doesn't address the customer's actual question
   - "unaddressed_question": Customer asked something specific that wasn't answered
   - "no_troubleshooting": Agent jumped to escalation without documenting troubleshooting
   - "golden_rules": Overall score below 3 on any dimension
6. Assess: does the response address the customer's issue? Include a next step? Use appropriate tone?

- Be fair and constructive. The goal is improvement, not punishment.
