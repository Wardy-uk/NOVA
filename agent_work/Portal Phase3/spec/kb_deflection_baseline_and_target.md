# KB Deflection Baseline And Target

## Domain

Portal knowledge-base deflection governance

## Problem

The portal already tracks KB deflection behaviour, but the 20-30% target remains operationally incomplete because there is no clear target configuration and no compact runtime-visible baseline/progress outcome.

## Desired Outcome

Someone using the running product in the intended operational surface can determine:

- the current deflection rate
- the configured target band
- whether current performance is on track, below target, or above target

## Constraints

- Keep the slice small.
- Preserve existing deflection and helpfulness flows.
- Do not widen this into general BI/reporting work.
- Do not require evaluator code inspection to judge success.
