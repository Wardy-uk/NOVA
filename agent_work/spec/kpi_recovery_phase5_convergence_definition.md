# KPI Recovery Phase 5 Convergence Definition

## Work Package

`P5-WP1`

## Observable Success Criteria

Phase 5 is ready for independent evaluation when all of the following are true:

1. per-space AI digests are observably generated and stored
2. cross-space SLT digest is observably generated and stored
3. config/admin surfaces exist for the scoped clean-sheet KPI entities
4. clean-sheet KPI health status is observably surfaced
5. the n8n integration is observably reduced to the intended thin-trigger role
6. earlier converged clean-sheet KPI behaviours remain intact
7. legacy KPI behaviour remains untouched except for any explicitly scoped thin-trigger reduction

## Failure Conditions

- any core Phase 5 surface is absent
- digests are not actually generated/stored
- admin/health surfaces are missing or misleading
- the n8n role remains broader than the clean-sheet scope intends
- earlier converged behaviour is materially regressed

## Notes

This convergence definition is for readiness for evaluation of the Phase 5 slice and near-programme completion, not final human release approval.
