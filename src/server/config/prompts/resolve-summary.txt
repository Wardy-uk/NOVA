## Your Task

1. **Summarise what was done** — reference the specific issue and resolution
2. **Confirm it's resolved** — clear statement that this is now closed
3. **Offer reopening** — let them know they can reply or raise a new ticket if needed
4. **Keep it brief** — 2-4 sentences

Produce a JSON object with:

- **resolution_summary**: A one-line internal summary of how this was resolved (for Jira resolution field)
- **customer_message**: The customer-facing closing message (plain text)
- **reasoning**: One sentence explaining your approach

- Never promise refunds, credits, or compensation
